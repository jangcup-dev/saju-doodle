# 사주낙서 (웹)

만세력 기반 사주와 매일의 운세를 손그림 스타일로 보여주는 웹앱입니다.

- 계산은 모두 기기 안에서 하고, 입력한 출생 정보는 그 기기의 브라우저에만 저장됩니다. 서버로 보내지 않습니다.
- 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 오프라인에서도 열립니다.
- 운세 풀이는 명리학의 전통 규칙(십신, 합·충·형·파·해, 12운성, 신살)으로 계산한 결과이며 재미와 참고용입니다.
